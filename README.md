# 古钱币收藏小程序

一个用于整理和管理古钱币收藏的微信小程序。

## 功能特性

### 核心功能
- ✅ 古钱币分类管理（先秦、汉唐、宋元、明清、民国）
- ✅ 按年代和版别详细分类
- ✅ 支持上传多张图片（正面、背面、其他）
- ✅ 收藏版别"点亮"功能
- ✅ 详细的统计数据展示
- ✅ 个人中心管理收藏

### 主要页面

1. **首页** - 展示收藏概览、快速入口和最近收藏
2. **分类** - 按分类和年代浏览所有版别
3. **详情** - 查看特定分类/年代下的所有版别
4. **上传** - 上传古钱币图片，支持最多 9 张
5. **统计** - 多维度的收藏统计分析
6. **我的** - 个人收藏管理和数据导出

## 技术特点

- 使用微信小程序原生开发
- 本地数据存储（wx.Storage）
- 响应式布局设计
- 支持图片选择和预览
- 数据持久化

## 快速开始

### 1. 导入项目
1. 下载微信开发者工具
2. 打开微信开发者工具
3. 选择"导入项目"
4. 选择项目目录：`e:\myapp\ancient-coin-collection`
5. 填写你的 AppID（或使用测试号）

### 2. 配置项目
打开 `project.config.json`，修改 `appid` 为你的小程序 AppID

### 3. 运行项目
点击"编译"按钮即可在模拟器中预览

## 使用说明

### 收藏版别
1. 进入"分类"页面
2. 选择钱币分类（如"明清货币"）
3. 选择年代（如"清朝"）
4. 在版别列表中找到要收藏的版别
5. 点击"收藏并上传"按钮
6. 选择图片并添加备注
7. 点击"保存"完成收藏

### 查看统计
1. 点击底部导航栏"统计"
2. 查看总体概况
3. 按分类查看收藏进度
4. 按年代查看详细统计

### 管理收藏
1. 进入"我的"页面
2. 查看所有收藏记录
3. 可删除单个收藏
4. 支持导出收藏清单
5. 可清空所有数据

## 数据说明

### 本地存储数据结构

**coinCategories** - 钱币分类
```javascript
[
  {
    id: 1,
    name: "先秦货币",
    eras: [
      { id: 101, name: "战国", years: "公元前 475-221 年" }
    ]
  }
]
```

**coinVariants** - 版别数据
```javascript
[
  {
    id: 1,
    eraId: 101,
    eraName: "战国",
    name: "刀币",
    subVariants: [
      {
        id: 101,
        name: "刀币 - 小平",
        collected: false,
        images: []
      }
    ]
  }
]
```

**userCollection** - 用户收藏
```javascript
[
  {
    id: 101,
    name: "刀币 - 小平",
    images: ["path/to/image1.jpg"],
    date: "2026-04-27"
  }
]
```

## 自定义扩展

### 添加新的分类
在 `app.js` 的 `initDefaultCategories()` 方法中添加新的分类数据

### 修改版别数据
在 `app.js` 的 `getEraVariants()` 方法中自定义版别列表

### 调整样式
修改 `app.wxss` 和各页面的 `.wxss` 文件

## 注意事项

1. **图片存储**: 当前版本使用本地临时路径，生产环境需要配置云存储
2. **数据备份**: 定期使用"导出数据"功能备份收藏数据
3. **AppID**: 需要替换 `project.config.json` 中的测试 AppID
4. **图标资源**: 需要自行添加 `images/` 目录下的图标文件
