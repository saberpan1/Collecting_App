# 图标设计系统 - TabBar 精致图标

## 设计理念

**"Apple级极简美学 + 古钱币文化元素"**

融合现代UI设计原则与传统文化气息，创造简洁而不简单、精致且统一的图标视觉体验。

## 图标清单

| 页签 | 图标名称 | 设计概念 | 文化寓意 |
|------|---------|---------|---------|
| 首页 | coin-icon | 古钱币 | 圆形方孔，钱币之形 |
| 分类 | book-icon | 典籍书架 | 书脊层叠，文化传承 |
| 统计 | chart-icon | 上升曲线 | 数据增长，收藏进度 |
| 我的 | seal-icon | 印章 | 庄重典雅，个人印记 |

## 设计规范

### 尺寸规格
- **图标容器**: 56×56rpx (居中显示)
- **图标实际尺寸**: 40-44×40-44rpx
- **安全区域**: 8rpx 留白
- **线条粗细**: 2-3rpx
- **圆角**: 统一采用 2-6rpx

### 颜色系统

#### 主色调
```
未选中态: #c4c4c4 (柔和灰)
选中态:   #1a1a1a (墨黑)
TabBar背景: linear-gradient(180deg, #ffffff 0%, #fafafa 100%)
```

#### 暗色模式
```
未选中态: #555555 (深灰)
选中态:   #ffffff (纯白)
背景:     linear-gradient(180deg, #1a1a1a 0%, #141414 100%)
```

### 视觉层次

| 层级 | 元素 | 透明度/效果 |
|------|------|------------|
| 底层 | 外框轮廓 | 100% 纯色 |
| 中层 | 内饰细节 | 渐变过渡 |
| 顶层 | 选中高光 | 阴影 + 缩放 |

### 设计描述
```
同心圆嵌套 + 中心方孔
外圆: 40rpx 边框 3rpx
内圆: 28rpx 边框 2rpx
方孔: 14rpx 旋转45°
```

### 未选中态
```

过渡: 0.25s ease
```

## 动画系统

### 选中动画 (iconPop)
```css
@keyframes iconPop {
  0%   { transform: scale(1); }
  40%  { transform: scale(1.18); }
  70%  { transform: scale(0.95); }
  100% { transform: scale(1.08); }
}

.duration: 0.4s
.timing: cubic-bezier(0.34, 1.56, 0.64, 1)
```

### 点击反馈动画
```css
.tabbar-item:active {
  opacity: 0.6;
  transform: scale(0.94);
}
```

### 减少动画模式
```css
@media (prefers-reduced-motion: reduce) {
  /* 禁用所有过渡和动画 */
  transition: none;
  animation: none;
}
```
