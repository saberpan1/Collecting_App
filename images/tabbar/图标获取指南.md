# TabBar 图标快速获取指南

## 快速获取精致图标

由于图标需要图形编辑器生成 PNG 文件，以下提供几种快速获取精美图标的方法：

---

## 方法一: IconFont 阿里巴巴矢量图标库 (推荐) ⭐

### 步骤

1. **访问 IconFont**
   ```
   https://www.iconfont.cn
   ```

2. **搜索图标关键词**
   - 首页: `home` 或 `house`
   - 分类: `category` 或 `folder`
   - 统计: `bar-chart` 或 `statistics`
   - 我的: `user` 或 `profile`

3. **下载图标**
   - 点击图标 → 加入购物车
   - 购物车 → 添加至项目
   - 项目 → 下载 PNG
   - 设置颜色: `#999999` (未选中) 和 `#1a1a1a` (选中)
   - 设置尺寸: `81×81` 或 `162×162` (@2x)

4. **命名规范**
   ```
   images/tabbar/
   ├── home.png              (首页未选中)
   ├── home-active.png       (首页选中)
   ├── category.png          (分类未选中)
   ├── category-active.png   (分类选中)
   ├── statistics.png         (统计未选中)
   ├── statistics-active.png (统计选中)
   └── profile.png          (我的未选中)
       └── profile-active.png   (我的选中)
   ```

2. 创建 81×81px 画板

4. 导出 PNG @2x

## 快速生成脚本 (ImageMagick)

如果你安装了 ImageMagick，可以使用以下命令生成图标:

```bash
# 安装 ImageMagick (macOS)
brew install imagemagick

# 或 Windows 使用 Scoop
scoop install imagemagick

# 生成图标
mkdir -p images/tabbar

# 首页图标 (未选中)
convert -size 81x81 xc:transparent \
  -fill "#999999" \
  -stroke "#999999" \
  -strokewidth 2 \
  -draw "polygon 40.5,15 15,40.5 30,40.5 30,60 51,60 51,40.5" \
  images/tabbar/home.png

# 首页图标 (选中)
convert -size 81x81 xc:transparent \
  -fill "#1a1a1a" \
  -stroke "#1a1a1a" \
  -strokewidth 2 \
  -draw "polygon 40.5,15 15,40.5 30,40.5 30,60 51,60 51,40.5" \
  images/tabbar/home-active.png
```

## 临时解决方案 (无需图标文件)

如果暂时无法获取图标，可以使用以下方案:

### 方案 1: 仅使用文字 TabBar

编辑 `app.json`:

```json
{
  "tabBar": {
    "color": "#999999",
    "selectedColor": "#1a1a1a",
    "list": [
      {
        "pagePath": "pages/index/index",
        "text": "首页"
      },
      {
        "pagePath": "pages/category/category",
        "text": "分类"
      },
      {
```
