- `category-active.png` - 分类图标 (选中)

### 我的图标

## 图标获取方式

1. **使用 emoji 临时替代**: 当前代码已使用 emoji (💰👤📤等) 作为临时图标，可以正常运行

2. **使用图标库**: 
   - IconFont: https://www.iconfont.cn/
   - IconPark: https://iconpark.oceanengine.com/
   - RemixIcon: https://remixicon.com/

3. **自行设计**: 使用 Figma、Sketch 等工具设计

## 临时解决方案

如果暂时没有图标，可以:
1. 使用微信开发者工具默认图标
2. 从 https://iconfont.cn 下载免费图标
3. 使用在线工具生成占位图：https://via.placeholder.com/

## 图标颜色建议

- 主色调：#8B4513 (棕色)
- 选中状态：#8B4513
- 未选中状态：#999999
